# Examen de Inteligencia Artificial 2026-2

# Jerson Americo Peña Salgueron

## Descripción

Este proyecto implementa un pipeline modular de Inteligencia Artificial en Python que incluye generación de datos sintéticos, preprocesamiento, aprendizaje supervisado, reducción de dimensionalidad mediante PCA y agrupamiento no supervisado mediante K-Means.
